# Classroom Student for Android

전자칠판 등 Android 기반 학교 기기에 설치하는 Classroom 클라이언트입니다. 기존 `android/PhoneUnlock` 앱과는 독립된 프로젝트이며 교육청 소개 자료에는 포함하지 않았습니다. 현재는 기기 호환 확인 전의 테스트 빌드입니다.

## 현재 구현 범위

- 선생님이 발급한 8자리 학생 코드로 장치 등록
- 서버 주소를 자동 사용해 코드만 입력하면 서버 상태를 확인하고 기기를 등록
- Android Keystore(AES-GCM) 기반 장치 토큰 암호화 저장
- 연결 상태를 알리는 foreground service와 자동 재연결
- 수업 메시지 수신 및 집중 모드(안내 화면/완전한 검은 화면)
- 전자칠판에서 사용자가 `다른 앱 위에 표시`를 허용하면 앱이 열려 있지 않을 때도 집중 화면 표시
- Android 시스템의 매회 동의를 거치는 화면 공유와 교사 화면 표시용 JPEG 전송
- HTTPS 웹 주소 열기 및 기기에 설치된 허용 앱 실행 요청(계산기·메모장 앱 또는 Android 패키지 이름)
- GitHub Android 릴리스 확인, APK 다운로드와 SHA-256 검증, Android 설치 확인 화면 열기
- 학교 MDM이 Lock Task를 허용한 경우에만 전자칠판 전용 모드 시작
- 서버 종료 PIN을 통한 앱 종료 요청

Windows 학생앱과 기능이 같지는 않습니다. Android는 화면 공유를 시작할 때마다 기기 사용자의 시스템 동의를 요구합니다. 웹 주소·앱 실행 명령이 앱이 백그라운드에 있을 때 도착하면 Android 제한 때문에 앱을 열어야 처리될 수 있으며, 해당 앱이 기기에 설치되어 있지 않으면 실행할 수 없습니다.

업데이트는 새 Android 릴리스가 공개되면 앱이 주기적으로 확인하고 APK를 받아 무결성을 검사합니다. 실제 업데이트 적용은 Android 설치 확인 화면에서 사용자가 승인해야 합니다. 완전 무인 설치는 학교의 Android Enterprise/EMM 등 기기 소유자 관리로 배포할 때에만 별도로 구성할 수 있습니다.

## 전자칠판 배포 전제

Android 8(API 26) 이상을 대상으로 합니다. 서버 연결과 학생 코드 등록에는 MDM 설정이 필요하지 않습니다. 앱은 재부팅 후 등록 정보를 바탕으로 다시 연결을 시도하며, 실제 시작 여부는 Android와 전자칠판 제조사 정책에 따라 달라질 수 있습니다. MDM은 앱 전환을 제한하는 선택적 키오스크 고정에 필요합니다. 실제 전자칠판의 Android 버전, Google Mobile Services 유무, 제조사 정책은 모델별로 다르므로 해당 기기에서 APK 설치 및 연결을 확인해야 합니다.

집중 화면을 다른 앱 위에 표시하려면 등록 화면에서 `다른 앱 위에 표시 허용`을 한 번
켜야 합니다. 이 권한은 Android 설정에서 사용자가 직접 승인하며 앱 등록이나 서버 연결에는
필요하지 않습니다. 오버레이는 일반 앱 위에 안내 또는 검은 화면을 표시하지만 Android
시스템 화면, 설정, 앱 전환을 완전히 잠그지는 않습니다. 완전한 키오스크 제한은 학교 MDM
전용 기기 설정으로 관리해야 합니다.

`Lock Task`는 허용된 관리 기기에서만 시작하며, 학생의 OS 제어를 우회하거나 제거·강제종료를 막는 기능은 넣지 않았습니다. 연결 알림도 표시합니다. 네트워크 없이 관리자 PIN을 확인할 수 없으므로 키오스크를 활성화하기 전에 학교 MDM에서 비상 복구 경로를 확인하세요.

## 빌드

Android Studio에서 이 폴더를 열거나, JDK 17 이상과 Android SDK 36이 설치된 환경에서 다음을 실행합니다.

```sh
./gradlew assembleDebug
```

테스트용 APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 이 빌드는 컴파일·Lint 검사를 통과했지만 실제 전자칠판에 설치해 등록, 연결, 화면 공유, 외부 앱 전환과 업데이트를 확인하지 않았습니다. 정식 배포 전에 같은 서명 키로 서명된 release 빌드, 기기별 시험, 학교 개인정보·운영 검토가 필요합니다. 부팅 후 자동 연결과 키오스크 고정은 기기 제조사 정책과 학교 MDM/EMM 설정에 따라 달라집니다.
