# Classroom v0.6.9

## 수업 운영 화면

- 메인 명령 영역은 화면 보기·집중 모드·메시지·URL 중심으로 정리하고, 앱 실행·프리셋·학생 그룹·수업 도구·기록은 `더보기` 창으로 분리했습니다.
- 예약 작업과 즉시 명령의 전달 결과를 `작업함`에서 학생별로 확인할 수 있습니다.
- 아직 전달되지 않은 예약 작업은 취소하고, 실패·거절된 학생에게만 재시도할 수 있습니다.
- 출결·참여 창에서 출석, 지각, 결석, 사유 결석과 메모를 수업 세션별로 저장합니다.
- 연결 상태 창에서 온라인·재연결 대기·첫 연결 전 장치를 마지막 신호 시간과 함께 확인합니다.
- 학생 도움 요청의 요청 시각과 처리 상태를 저장해 알림 흐름과 연결했습니다.

## 서버·안정성

- 예약 명령 취소·재시도 API와 명령 상세 상태를 추가했습니다.
- 출결 기록과 장치 도움 요청 상태를 Durable Object SQLite에 저장하는 additive migration을 추가했습니다.
- 장치 응답 결과와 연결 지연을 교사 화면에 노출하고, 오프라인 장치의 예약 작업은 재연결 뒤 전달됩니다.
- 웹 콘솔·학생 앱·설치 도구 버전을 0.6.9로 맞추고 서비스 워커 캐시를 갱신했습니다.
