# Classroom v0.5.40

## 교사 대시보드 정리

- 상시 노출되던 `수업 흐름`과 `수업 신호 센터` 패널을 제거해 학생 목록과 수업 명령에 시선이 집중되도록 정리했습니다.
- 해당 패널에만 연결돼 있던 저장 타이머·단계·신호 렌더링 코드를 함께 제거해 사용하지 않는 상태가 남지 않도록 했습니다.
- 학생 목록의 도움 요청, 확인 필요 필터와 학생 상세 화면은 유지했습니다.
- CSS의 중복 카드·반응형 규칙을 정리해 화면별 구분을 더 명확하게 했습니다.

## 확인 항목

- 브라우저 정적 품질 검사
- Cloudflare Pages 정적 fallback·프록시 검사
- 학생 다운로드 Worker 검사
- Pages 산출물 빌드
