# 0.4.0-beta.19

## Android

- PC 잠금은 확인창 없이 즉시 실행
- PC 잠금 해제와 절전·재시작·종료는 앱 확인창 없이 시스템 생체인증을 바로 표시
- 위젯 잠금·PC 켜기 작업을 백그라운드 작업으로 처리해 클릭 누락과 UI 멈춤 개선
- 위젯 내부 여백 축소 및 작은 크기부터 세로·가로 크기 조절 지원
- 하단 플로팅 네비게이션의 선택 표시와 여백 개선
- 자동 잠금 해제 성공 알림을 휴대폰 감지와 재실 센서 감지로 분리

## Windows

- 자동화 알림은 감지 신호가 아니라 Windows 로그인 성공 보고 이후에만 표시
- 휴대폰 근접 자동 해제와 재실 센서 자동 해제의 성공 원인을 Credential Provider에서 구분
