# Classroom v0.9.1

## 학생 장치 전원·잠금

- 교사 콘솔의 전원·잠금 도구에서 온라인 학생 PC를 Windows 잠금(Windows+L), 종료, 재시작할 수 있습니다.
- 전원 명령은 학급 권한과 활성 수업을 확인하고, 선택된 온라인 장치에만 전달됩니다.
- 종료·재시작·잠금은 되돌릴 수 없는 동작이므로 확인 대화상자와 감사 가능한 작업 기록을 거칩니다.
- 완전히 꺼진 PC는 WebSocket 명령을 받을 수 없습니다. 켜기는 학교망 WOL 중계기와 BIOS/UEFI 설정을 연결한 뒤 별도 통합으로 활성화해야 합니다.

## 구형 학생 앱 업데이트 호환성

- 업데이트 매니페스트에 구형 클라이언트가 이해하는 packageUrl(전체 Windows 패키지)을 유지합니다.
- 최신 학생 서비스는 허용된 studentPackageUrl(학생 전용 패키지)을 우선 사용하고, 문제가 있으면 호환 URL로 내려갑니다.
- 실행 중인 서비스는 지연 자동 시작과 실패 시 재시작 정책을 다시 적용하고, 로그인한 사용자 세션의 학생 화면을 복구합니다.
