# Classroom v0.6.0

## 수업 운영 워크스페이스

- `확인 필요` 신호를 상시 카드가 아닌 알림 서랍으로 모았습니다. 도움 요청은 교사가 확인 처리하면 학생 앱에서도 요청 상태가 해제됩니다.
- 집중 모드, 안내 메시지, HTTPS URL, 승인 앱 조합을 수업 프리셋으로 저장하고 선택 학생 또는 전체 학생에게 실행할 수 있습니다.
- 학생 장치를 학급별 그룹으로 묶고 그룹 단위로 선택해 명령을 보낼 수 있습니다.
- 기존 감사 기록을 수업 기록 화면과 CSV 다운로드로 연결했습니다.
- 삭제했던 목표·단계·타이머는 `수업 도구` 서랍에서 필요할 때만 열어 쓰도록 복원했습니다.

## 저장과 안전성

- 그룹과 프리셋은 학급 범위의 Durable Object SQLite에 저장하고, 브라우저에도 읽기용 캐시를 둡니다.
- URL은 HTTPS만 허용하며, 그룹은 현재 학급에 등록된 장치만 포함할 수 있습니다.
- 도움 요청 확인 명령은 기존 명령 큐·감사 기록·학생 앱의 가시적 상태 경로를 사용합니다.
- 학생 앱과 교사 콘솔을 함께 `0.6.0`으로 올려 새 명령 프로토콜을 맞췄습니다.
