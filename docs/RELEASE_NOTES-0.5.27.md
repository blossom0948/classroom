# Classroom v0.5.27

- 홈 화면을 학생 모니터 중심으로 재배치했습니다. 화면 보기를 켜면 같은 학생 그리드가 저화질 모니터 벽으로 전환되며, 페이지·전체 화면·학생별 상세 보기를 제공합니다.
- 학생 이름과 번호는 화면을 가리지 않는 우측 하단 Flip 스타일 라벨로 정리했습니다.
- 설정 화면의 비밀번호 카드가 좁은 열로 압축되던 문제를 없애고, 약관과 개인정보처리방침은 하단 푸터 링크로 옮겼습니다.
- 홈의 인사·날씨는 카드 밖의 상단 문맥으로 정리하고, 수업 제어와 수업 요약을 더 작게 구성했습니다.
- Pages 프록시를 통한 Secure/HttpOnly 쿠키 세션을 기본으로 전환하고, Google 리디렉션 로그인 결과를 세션 복원보다 먼저 처리하도록 수정했습니다.
- 학생 앱은 연결·자동 연결·화면 공유·버전·업데이트·종료만 남긴 간결한 화면으로 정리했습니다. 제목 표시줄 X도 관리자 종료 비밀번호 확인을 거칩니다.
- 학교 IT용 읽기 전용 장치 준비 상태 점검 스크립트와 Intune/GPO 운영 가이드를 추가했습니다.
