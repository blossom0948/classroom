# Classroom v0.6.2

## 학교 게스트 운영 권한과 다크모드 대비 개선

- 학교 게스트 로그인에서도 수업 시작·종료, 학생 상태 확인, 학생 화면 보기, 메시지·URL·앱 명령, 집중 모드, 원격 지원, 그룹·프리셋·수업 기록을 사용할 수 있습니다.
- 학생 코드 발급·재발급, 장치 연결 해제, 관리자 계정·비밀번호·보안 설정과 학교 게스트 비밀번호 관리는 계속 관리자만 사용할 수 있습니다.
- 게스트 로그인 화면의 안내 문구를 실제 사용 가능한 기능과 관리자 전용 기능으로 구분했습니다.
- 다크모드의 수업 화면, 학생 카드, 학생 상세/화면 보기, 명령·도구·그룹·프리셋·리포트 창, 입력창과 관리자 패널의 배경·테두리·글자 대비를 통일했습니다.
- 서비스 워커 캐시를 갱신해 이전 밝은 스타일이 남지 않도록 했습니다.

## 확인 항목

- 웹 JavaScript·Worker 구문 검사
- 웹 품질·Pages 프록시·Worker 다운로드 검사
- .NET Release 빌드 및 GitHub CI
