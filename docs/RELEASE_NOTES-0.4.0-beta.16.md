# 0.4.0-beta.16

beta.15의 자동 연결·재실 자동화·테마·플로팅 하단바·위젯 기능을 포함한 배포판입니다.

## 수정

- Windows 내장 재실 센서 API를 .NET 8 호환 C#/WinRT 투영으로 연결했습니다. 기존의 원시 Windows 메타데이터 참조 때문에 Windows 빌드가 실패하던 문제를 해결합니다.
- 재실 센서가 지원되는 Windows 11 PC에서는 센서의 `있음/없음` 변화가 자동 잠금 흐름으로 전달됩니다. 센서가 없는 PC는 기존의 인증 휴대폰·Bluetooth 기반 동작을 그대로 사용합니다.
- Android 버전 코드를 19로 올려 이전 APK 위에 정상 업데이트되도록 했습니다.
