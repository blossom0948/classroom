# Classroom v0.5.36

## 집중 모드 표시 방식 선택

- 교사 콘솔에서 집중 모드 표시 방식을 `안내문` 또는 `검은 화면`으로 선택할 수 있습니다.
- `검은 화면`은 학생 Desktop에 텍스트 없는 검은 전체화면을 표시합니다.
- 선택한 방식은 교사 콘솔에 저장되어 다음 접속에도 유지됩니다.
- 기존 집중 모드 해제, 수업 종료 시 정리, 서버 연결 단절 시 fail-safe 해제 동작은 그대로 유지됩니다.

## 로그인 진입 순서

- 랜딩 페이지의 모든 기본 시작 버튼은 `학교 로그인`을 먼저 엽니다.
- `관리자 로그인`을 선택했을 때는 `로그인` 탭이 기본으로 열리고, `회원가입`은 탭에서 선택할 수 있습니다.

## 화면 구분성 개선

- 학교 로그인과 관리자 로그인에 각각 `01 · 기본 로그인`, `02 · 관리자 전용` 표식을 두어 진입 순서를 분명히 했습니다.
- 관리자 로그인·회원가입, 수업 필터, 관리자 대상 선택은 현재 선택값이 채워진 버튼으로 표시됩니다.
- 관리자·설정 화면의 기능 카드는 목적별 색상 레일을 적용해 설정, 명단, 권한, 보안 항목을 빠르게 구분할 수 있습니다.
