# Classroom v0.6.1

## 수업 콘솔 시인성 정리

- 학생 목록의 필터·검색 영역과 선택 학생 명령 영역을 분리했습니다.
- `화면 확인`, `집중 상태`, `학생 안내`, `수업 도구`를 색상과 설명으로 구분했습니다.
- 버튼에 기능 설명과 대상이 드러나는 라벨·툴팁을 추가했습니다.
- 수업 도구, 프리셋, 학생 그룹, 수업 기록 창에 서로 다른 색상·아이콘·헤더를 적용했습니다.
- 메시지·URL·승인 앱 명령 창도 명령 종류에 따라 헤더 색상이 바뀝니다.
- 좁은 화면에서는 필터와 명령 그룹이 읽기 쉬운 세로 흐름으로 전환됩니다.

## 확인 항목

- 웹 JavaScript·Worker 구문 검사
- 웹 품질·Pages 프록시·Worker 다운로드 검사
- .NET Release 빌드 및 GitHub CI
