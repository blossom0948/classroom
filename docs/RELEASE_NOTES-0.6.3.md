# Classroom v0.6.3

## 검은 화면 집중 모드 전달 수정

- 교사 콘솔에서 선택한 `검은 화면` 표시 방식을 Worker가 학생 장치 명령까지 그대로 전달하도록 수정했습니다.
- 학생 앱의 검은 화면 오버레이는 안내 문구를 숨기고 텍스트를 비운 뒤 순수한 검은 화면만 표시합니다.
- 안내문 집중 모드는 기존처럼 메시지를 표시합니다.
- 교사가 현재 사용할 수 있는 화면 기능은 학생 화면 공유 종료, 검은 화면 집중 모드, 학생 동의 후 원격 지원입니다. 실제 학생 PC 모니터 전원 끄기는 포함하지 않았습니다.

## 세션 복구 및 예약 명령

- 교사·게스트 세션을 30일 수명으로 늘리고, 사용 중인 세션은 만료 전에 자동 갱신합니다.
- 일시적인 서버·네트워크 오류가 나도 저장된 로그인 토큰을 지우지 않고 재연결합니다. 실제 만료나 로그아웃 요청은 기존처럼 로그인 화면으로 전환됩니다.
- 메시지·URL·승인 앱 명령을 지금 또는 1·5·10·30분 뒤로 예약할 수 있습니다. 서버가 실행 시각을 저장하므로 오프라인 장치는 다시 온라인이 된 뒤 예약 시각이 지났으면 바로 명령을 받습니다.

## 작은 비밀

- 콘솔에서 입력창을 닫고 `CLASSROOM`을 입력하면 숨겨진 축하 애니메이션이 나타납니다.
