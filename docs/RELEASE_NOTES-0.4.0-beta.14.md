# 0.4.0-beta.14

beta.13의 자동 원격 연결·재실 센서·테마·플로팅 하단바·위젯·확인 팝업 기능을 포함한 안정 배포판입니다.

## 배포 수정

- Windows 내장 재실 센서에 필요한 Windows SDK 대상 버전을 바로잡았습니다.
- Windows 설정 앱의 테마 저장 경로 컴파일 문제를 수정했습니다.

## 포함된 주요 기능

- PC와 휴대폰의 **원격 연결 켜기**에서 Tailscale의 최초 로그인·VPN 승인만 끝내면 LAN·VPN 주소 선택과 갱신, 재연결을 자동 처리합니다.
- Windows 11 24H2 이상 지원 PC에서는 **사람이 없으면 잠금**만 켜서 내장 재실 센서를 사용합니다.
- Android와 Windows에 밝게·어둡게·시스템 테마, Android 플로팅 하단바, 빠른 확인 팝업, 자동 잠금 해제 알림을 추가했습니다.
- Android 위젯에 PC 이름, 켜기·절전·재시작·잠금·잠금 해제, 위젯별 테마와 투명도를 추가했습니다.
