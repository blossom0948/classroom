# Classroom v0.9.0

## 집중모드와 학생 앱 복구

- 집중모드 오버레이가 여러 모니터의 전체 가상 화면을 덮도록 보강했습니다.
- Windows 가상 데스크톱을 전환하면 현재 데스크톱에 오버레이를 다시 붙여 집중모드가 따라옵니다.
- 검은 화면 모드는 콘텐츠·문구 없이 완전한 검은 화면으로 유지됩니다.
- 학생 서비스가 로그인 세션과 화면 감시 프로세스를 짧은 주기로 확인해 앱이 종료되거나 충돌해도 자동 복구합니다.
- 서비스 자동 시작을 지연 자동 시작으로 정리해 Windows 부팅·네트워크 초기화 중의 실행 실패를 줄였습니다.
- 설치·업데이트 시 실행 중인 화면 프로세스의 경로를 더 안정적으로 확인해 파일 잠금 오류를 줄였습니다.

## 학급 전환과 반 관리

- 홈 화면 학급 선택기를 학년 탭과 가로형 학급 타일로 개편했습니다.
- 학생 코드 화면에서 학급 이름·학년·반 번호·과목을 수정하거나 학급을 삭제할 수 있습니다.
- 학급 삭제 시 연결된 학생 코드·장치·예약 작업·그룹·프리셋을 함께 정리하고 감사 기록은 보존합니다.

## 안전한 운영 범위

- 학생이 창을 닫거나 앱이 비정상 종료되어도 서비스·감시 프로세스가 다시 실행합니다.
- Windows 작업 관리자와 운영체제의 긴급 종료 기능을 차단하지 않으며, 관리자 종료 비밀번호와 감사 흐름은 그대로 유지합니다.
