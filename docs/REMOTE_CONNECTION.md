# 원격 연결

Phone Unlock은 휴대폰과 PC의 물리적인 거리를 측정해서 연결하는 프로그램이 아닙니다. 두 기기 사이에 TCP 48231번으로 서로 도달할 수 있는 네트워크 경로가 있으면 연결됩니다.

지원 경로:

- 같은 공유기의 Wi-Fi ↔ Ethernet
- Tailscale 또는 WireGuard 같은 암호화된 사설 VPN
- 회사·학교 등에서 두 장치 사이의 사설 라우팅이 허용된 네트워크

설정 앱이 만드는 QR에는 PC의 모든 IPv4 주소가 들어갑니다. Android 앱은 QR의 주소를 순서대로 시도하고, 현재 연결할 수 있는 LAN 또는 VPN 주소를 자동으로 선택합니다. 따라서 PC가 Ethernet이고 휴대폰이 Wi-Fi인 것은 문제가 아닙니다.

## 장소가 달라도 연결하기

1. PC와 Android에 같은 Tailscale 네트워크를 설치하고 같은 계정 또는 같은 tailnet에 로그인합니다.
2. PC에서 Tailscale이 실행 중인 상태로 Phone Unlock 설정 앱의 **연결 QR 코드 만들기**를 다시 누릅니다.
3. Android에서 QR을 스캔합니다. `100.x.x.x` 주소가 QR의 연결 후보에 포함되면 원격에서도 이 주소를 자동으로 시도합니다.
4. Android 앱의 상시 알림이 `PC 이름 · 연결됨`으로 바뀌는지 확인합니다.

Tailscale의 안정적인 사설 IP와 MagicDNS는 NAT나 장소가 바뀌어도 기기 간 연결에 사용할 수 있습니다. PC 서비스는 VPN 어댑터 주소에도 바인딩되고, 설치 시 사설 VPN 주소 대역만 별도 방화벽 규칙으로 허용합니다.

## 연결되지 않는 경우

- VPN 앱이 양쪽 기기에서 연결됨인지 확인합니다.
- Phone Unlock을 VPN 연결 후 다시 페어링해 주소 후보를 갱신합니다.
- PC의 `PhoneUnlockService`가 실행 중인지 확인합니다.
- VPN에서 PC의 TCP 48231이 차단되지 않았는지 확인합니다.
- 게스트 Wi-Fi나 AP isolation처럼 장치 간 통신을 막는 네트워크는 사용할 수 없습니다.

공용 인터넷에 PC 포트 48231을 직접 포워딩하는 방식은 지원하지 않습니다. 원격 연결에는 반드시 VPN 또는 별도의 검증된 사설 라우팅을 사용하세요. Phone Unlock은 VPN 앱을 대신 설치하거나 계정에 로그인하지 않습니다. PC가 절전·종료 상태이면 일반 연결은 끊기며, Wake-on-LAN은 PC가 있던 로컬 LAN의 브로드캐스트가 전달되는 환경에서만 동작합니다. 다른 장소에서 완전히 꺼진 PC를 켜려면 VPN 외에 상시 켜진 공유기·WOL 릴레이·원격 전원 장치 중 하나가 필요합니다.
