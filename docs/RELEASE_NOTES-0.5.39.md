# Classroom v0.5.39

## 원격 지원

- 교사가 특정 학생 PC에 원격 지원을 요청하고, 학생이 명시적으로 허용한 뒤에만 연결됩니다.
- 학생 화면에 교사 이름, 만료 시간, 빨간 고정 표시, 즉시 종료 버튼을 제공합니다.
- 교사는 별도의 원격 제어 시작 단계를 거쳐 마우스·키보드 입력을 보낼 수 있습니다.
- 입력은 허용된 포인터 이벤트와 일반 키로 제한하며, Alt/Windows 키·셸·파일·UAC 입력은 차단합니다.
- 학급/수업/장치 바인딩, 동의 시간 초과, 세션 만료, sequence 재생 방지, 초당 30건 제한, 연결 끊김 자동 종료를 적용했습니다.
- 요청·허용·종료 상태만 감사 기록에 남기고, 원격 입력과 화면 프레임은 저장하지 않습니다.

## 화면과 안정성

- 원격 지원 중 화면 공유 주기를 250ms까지 낮춰 포인터 제어 피드백을 개선했습니다.
- 서버 재시작·재연결 뒤 이전 동의 창이 다시 뜨지 않도록 대기 명령을 폐기합니다.
- 원격 제어 UI를 주황/빨강 계열로 분리해 일반 화면 보기·메시지·집중 명령과 구분했습니다.
- 원격 지원 종료 시 학생 화면의 집중 모드가 자동으로 해제되도록 정리 명령 전달을 보장합니다.

## 확인 항목

- 프로토콜 및 서버 self-test, 브라우저 정적 품질 검사, Worker/Pages 프록시 검사를 추가했습니다.
- 실제 Windows 입력 주입은 Windows 실기기 또는 VM에서 수동 검사가 필요합니다.
