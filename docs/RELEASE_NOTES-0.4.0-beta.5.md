# 0.4.0-beta.5

## 이번 버전

- Android에 **약한 얼굴인식 호환 모드**를 추가했습니다. 제조사가 `BIOMETRIC_WEAK`으로 분류한 얼굴인식도 사용할 수 있지만, 서명 키와 생체인식의 암호학적 연결이 약해지는 명시적 호환 모드입니다. 켜면 기존 PC를 다시 연결해야 합니다.
- Windows 설정 앱에 자동잠금 에이전트 연결 상태와 **자동잠금 감시 시작** 버튼을 추가했습니다.
- Android의 PC 페어링이 끊기거나 앱에서 PC를 삭제하면 연결이 끊긴 뒤 설정한 유예 시간이 지나 Windows를 잠급니다. 이 기능은 최신 설치본의 에이전트가 로그인 세션에서 실행 중이어야 합니다.
- **휴대폰이 가까워지면 자동 잠금 해제** 옵션을 추가했습니다. 기본값은 꺼짐이며, 켜면 근접 신호가 잠금화면의 Phone Unlock 인증을 자동 시작합니다. 집에서만 사용하세요.
- 서비스가 사용자 세션 에이전트가 없어도 근접 자동해제 신호를 준비하도록 보강했습니다.

## 업데이트 후 확인

1. Windows에서 `PhoneUnlock-Setup.exe`를 설치하고 UAC에서 **예**를 누릅니다.
2. 설정 앱의 **휴대폰 거리 이탈 보호**에서 자동잠금을 켠 뒤 **자동잠금 감시 시작**을 한 번 누릅니다.
3. 앱에 `자동잠금 에이전트 연결됨`이 보이는지 확인합니다.
4. Android 얼굴인식이 계속 거부되면 앱의 **약한 얼굴인식 호환 모드 사용**을 켜고 해당 PC를 다시 연결합니다.
5. 자동 잠금 해제는 같은 화면에서 별도로 켤 수 있습니다. 잠금화면 인증을 생략할 수 있어 기본값은 꺼져 있습니다.
