# Classroom v0.5.26

- 좁은 PC 폭에서 인사말, 학급 선택, 날짜·날씨가 서로 밀리지 않도록 헤더를 한 줄 흐름으로 재배치했습니다.
- 모바일의 날짜·날씨를 같은 행에 유지하고, 작은 화면에서도 Classroom 이름과 하단 메뉴 글자가 세로로 무너지지 않게 보완했습니다.
- 화면 전환, 카드 호버, 대화상자 모션을 짧고 안정적인 전환으로 정리하고 `prefers-reduced-motion` 환경을 계속 존중합니다.
- 카드·도구 모음·대화상자의 최소 폭과 줄바꿈 규칙을 정리해 글자 잘림·가로 넘침을 줄였습니다.
- 브라우저용 중복 종료 아이콘은 숨기고, 설치형 콘솔의 Windows 제목 표시줄 종료 흐름을 우선합니다.
