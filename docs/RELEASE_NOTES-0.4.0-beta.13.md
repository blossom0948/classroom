# 0.4.0-beta.13

## 자동 연결과 재실 자동화

- PC와 휴대폰에서 **원격 연결 켜기**를 한 번 누르면 Tailscale 설치·로그인 화면을 엽니다. 운영체제의 VPN 허용과 로그인만 끝내면, 이후 Phone Unlock은 LAN과 VPN 주소를 자동 갱신하고 재연결합니다.
- PC의 Tailscale/WireGuard 주소가 바뀌어도 인증된 연결 정보로 휴대폰에 자동 전달합니다. 다시 QR을 만들거나 재페어링할 필요가 없습니다.
- Windows 11 지원 하드웨어에서는 **사람이 없으면 잠금**만 켜면 토큰·허브 주소 없이 PC 재실 센서를 사용합니다. 자동잠금 감시는 설치 직후와 Windows 로그인 때 자동 시작되며, 사람이 사라진 뒤 설정한 시간(기본 10초)이 지나면 PC를 잠급니다.
- 신뢰한 휴대폰 또는 재실 센서가 다시 감지되어 자동 잠금 해제 신호를 보낼 때 PC 트레이와 휴대폰에 알림을 표시합니다.

## Android 화면과 위젯

- Android에 시스템·밝게·어둡게 테마와, 카드형 플로팅 하단바를 추가했습니다.
- PC 잠금 해제·잠금·전원 명령은 앱과 위젯에서 빠른 확인 팝업을 먼저 표시합니다. 생체인증 버튼을 누르면 즉시 Android 생체인식으로 이어집니다.
- 위젯에 PC 이름, 켜기·절전·재시작·잠금·잠금 해제를 넣고, 위젯 전용 밝게/어둡게/시스템 테마와 투명도를 추가했습니다.
- 원격 생체인증 성공 결과는 휴대폰 앱 안에서 표시하고, PC에는 `휴대폰에서 생체인식으로 잠금 해제` 알림을 띄웁니다.

## Windows 설정 앱

- Windows 설정 앱에 시스템·밝게·어둡게 테마, 읽기 쉬운 대비, 짧은 화면 전환 애니메이션, 원격 연결 버튼을 추가했습니다.
- 설정 화면에서 나가기(Esc 또는 Alt+← 포함)는 앱을 종료하지 않고 연결된 휴대폰 목록으로 돌아갑니다.

## 알아둘 점

- Android VPN 권한과 Tailscale 계정 로그인은 Android/서비스 정책상 최초 한 번 사용자가 승인해야 합니다. Phone Unlock은 그 다음부터 주소 선택·갱신·재연결을 자동 처리합니다.
- Windows 내장 재실 센서는 Windows 11 24H2 이상과 지원되는 하드웨어에서만 동작합니다. 지원하지 않는 PC에서는 기존 휴대폰 근접 감지 또는 SmartThings/Home Assistant 연동을 사용할 수 있습니다.
- SmartThings Station을 공식 API로 읽으려면 SmartThings 계정 API 인증이 필요합니다. 공개된 토큰 없는 로컬 재실 상태 인터페이스는 제공되지 않습니다.
