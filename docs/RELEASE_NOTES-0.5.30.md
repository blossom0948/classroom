# Classroom v0.5.30

## 학교 로그인과 학생 앱 설치

- 일반 교사 진입 화면을 `학교 로그인` 한 가지 기본 동작으로 정리했습니다.
- 이메일·비밀번호·Google 대체 인증과 회원가입은 `관리자 로그인`을 선택했을 때만 표시됩니다.
- 로그인 전 랜딩 페이지와 관리자 화면에서 학생용 설치 도우미를 내려받을 수 있습니다.
- 단독으로 받은 `Classroom.Student.Setup.exe`도 공식 Windows 패키지를 자동으로 내려받아 설치할 수 있습니다.

## 재부팅 후 자동 실행과 중복 등록 방지

- 학생 등록의 Desktop IPC 설정을 `%ProgramData%\Blossom Classroom Student\desktop-config.json`에 저장합니다.
- 학생 Windows 서비스는 자동 시작으로 등록하고, 학생 Desktop 감시 프로세스는 컴퓨터의 Windows 로그인 시 자동으로 시작합니다.
- 학생 Desktop은 기본적으로 창을 띄우지 않고 알림 영역에서 실행됩니다. `상태 열기`를 눌렀을 때만 상태 창을 표시합니다.
- 이미 설치된 PC에서 설치 도우미를 다시 실행하면 기존 등록을 재사용하므로 학생 코드를 다시 입력하거나 학생을 중복 등록하지 않습니다.
- 설치 완료 알림창을 제거하고, 설치가 끝나면 백그라운드 실행 상태로 정리합니다.

## 운영·보안 참고

- 이 버전은 Windows 서비스와 자동 시작을 구성하지만, 작업 관리자에서 프로세스를 절대 종료할 수 없게 만드는 기능은 제공하지 않습니다. 학교 장비의 강제 실행·삭제 방지에는 Intune, GPO, Assigned Access, 표준 사용자 권한 등 학교 IT 정책을 함께 적용해야 합니다.
- 학생 화면 캡처는 교사가 화면 보기를 요청한 동안에만 연결되며, 앱·창·도메인·네트워크 등의 상태 정보와 같은 학교 운영 범위에서 처리됩니다.
