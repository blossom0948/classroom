# Classroom v0.8.0

## 학급 전환과 반 관리

- 홈 화면의 학급 선택기를 학년 탭과 가로형 학급 타일로 개편했습니다.
- 학생 코드 화면에서 학급별 학생 명단을 바로 열 수 있습니다.
- 관리자는 학생 코드 화면에서 학급 이름·학년·반 번호·과목을 수정하거나 학급을 삭제할 수 있습니다.
- 학급을 삭제할 때 연결된 학생 코드, 장치, 예약 작업, 그룹과 프리셋을 함께 정리하고 감사 기록은 보존합니다.
- 진행 중인 수업이 있는 학급은 먼저 수업을 종료해야 삭제할 수 있습니다.

## 화면 계층과 시인성

- 학급 메뉴, 모바일 명령 시트, 상세 패널, 알림 드로어, 토스트와 이스터 에그의 고정 계층을 재정리했습니다.
- 서로 다른 창이 겹칠 때 우선순위가 뒤섞이지 않도록 공통 z-index 스택을 적용했습니다.
- 학급 카드와 수정 창을 모바일에서도 한눈에 읽고 조작할 수 있도록 반응형 레이아웃을 보강했습니다.
