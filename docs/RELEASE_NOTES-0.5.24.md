# Classroom v0.5.24

- 학생 앱 업데이트가 재부팅 대기 방식에서 격리된 업데이트 도우미 방식으로 변경되었습니다. 검증된 패키지를 적용할 때 학생 서비스와 화면을 순서대로 다시 시작하며 Windows 재부팅은 요구하지 않습니다.
- 학생 화면을 연결 상태, 버전, 화면 공유 상태, 업데이트 확인, 프로그램 종료로 간결하게 정리하고 콘솔과 같은 색상·둥근 표면 언어를 적용했습니다.
- 운영 Pages 교사 세션은 HttpOnly·Secure 쿠키를 사용하고 게스트 세션은 브라우저 세션 쿠키로 제한했습니다. 로컬 개발 환경에는 기존 bearer-token fallback을 유지합니다.
- 반 선택 레이어의 표시 우선순위와 좁은 화면의 텍스트 흐름을 보강하고 사용하지 않는 학생 카드 밀도 버튼을 제거했습니다.
