# Classroom v0.6.8

## 반응형·접근성 최종 점검

- 휴대폰 학생 필터를 라벨 길이에 맞는 컴팩트 칩으로 고정해 한 화면에서 흐름을 파악하고 필요한 경우 가로로 넘겨 볼 수 있게 했습니다.
- 관리자 로그인·회원가입 화면이 작은 화면에서 아래쪽 버튼을 잘라내지 않고 안전 영역까지 세로 스크롤되도록 보완했습니다.
- 닫힌 모바일 명령 시트를 `aria-hidden`·`inert` 상태로 동기화해 화면 밖 명령 버튼이 키보드·보조기술에 노출되지 않게 했습니다.
- 브라우저 저장소를 사용할 수 없는 환경에서도 초기화·테마·정렬·Google 로그인 복구가 예외로 전체 앱을 멈추지 않도록 저장소 접근을 안전한 래퍼로 통일했습니다.
- 웹 콘솔·학생 앱·설치 도구의 버전을 0.6.8로 맞추고 서비스 워커 캐시를 갱신했습니다.

## 확인 항목

- JavaScript 구문, DOM 연결, Worker·Pages 프록시·다운로드 품질 검사
- 1440px·1024px·821px·390px·320px 화면의 레이아웃 및 가로 넘침 점검
- 라이트·다크 모드, 모바일 명령 시트, 관리자 로그인 스크롤, 필터 칩 터치 영역 점검
