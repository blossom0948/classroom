# Classroom v0.7.0

## 네이티브 표면·모션 리디자인

- `classroom-main/agents.md`의 UI 규칙을 전체 콘솔에 적용했습니다.
- 랜딩, 학교 로그인, 관리자 로그인, 수업 콘솔, 학생 코드, 관리자, 설정 화면을 중립 Slate/Zinc 표면과 역할별 포인트 색으로 재구성했습니다.
- 카드·버튼·탭·학생 타일에 2–3중 Soft Layered Shadow와 스프링형 눌림/호버 피드백을 적용했습니다.
- 대화상자와 상세 패널을 공통 시트 모션으로 통일하고, 수업 도구·작업함·출결·연결 상태 등 각 창에 고유한 색상 정체성을 부여했습니다.
- 모바일에서는 하단 명령 시트·바텀 내비게이션·전체 화면 패널을 동일한 물리적 모션 언어로 정리했습니다.
- 다크 모드와 모션 감소 환경에서도 동일한 정보 위계와 대비를 유지하도록 토큰을 재정의했습니다.
