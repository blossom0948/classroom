# Classroom v0.6.7

## 모바일 교사 콘솔 개편

- 모바일 화면을 데스크톱 축소판이 아닌 수업 맥락·수업 제어·학생 목록·하단 명령 시트 순서의 전용 흐름으로 다시 구성했습니다.
- 학생 목록은 검색·상태 필터·정렬에 집중하고, 화면 보기·집중 모드·메시지·URL·앱·수업 도구는 한 번에 여닫는 학생 제어 시트에 모았습니다.
- 선택한 학생 수와 적용 범위를 제어 버튼과 시트에 함께 표시하며, 시트는 바깥 영역 탭·닫기·Esc로 안전하게 닫힙니다.
- 수업 상태 카드, 요약 지표, 하단 탐색, 학생 카드, 상세 패널, 알림 패널, 설정·관리 화면과 대화 상자의 휴대폰 터치 영역과 정보 위계를 정리했습니다.
- 다크 모드의 모바일 표면·텍스트·입력창·명령 시트·탐색 막대를 별도로 보정해 밝은 패널이나 어두운 글자가 섞이지 않게 했습니다.
- `prefers-reduced-motion`을 존중하면서도 일반 환경에서는 가벼운 진입·시트 전환 애니메이션을 제공합니다.

## 확인 항목

- JavaScript 구문 및 정적 DOM 연결 검사
- 웹 품질·Pages 프록시·Worker 다운로드 검사
- 휴대폰 폭의 수업·학생 제어·다크 모드·보조 패널 시각 검토
