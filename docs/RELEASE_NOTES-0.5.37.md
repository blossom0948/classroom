# Classroom v0.5.37

## 수업 흐름

- 교사 콘솔 수업 화면에 `수업 흐름`을 추가했습니다.
- 오늘의 목표, 준비·설명·실습·마무리 단계, 10·20·30·45분 타이머를 학급별로 정리할 수 있습니다.
- 목표와 현재 단계, 남은 시간을 기존 전체 메시지 기능으로 학생에게 안내할 수 있습니다.
- 수업 흐름은 해당 교사 콘솔 브라우저에 학급별로 저장됩니다.

## 도움 요청과 수업 신호 센터

- 학생용 Windows 앱에 수업 중 `도움 요청` / `요청 취소` 버튼을 추가했습니다.
- 요청은 기존 학생 상태 전달 경로를 사용하며, 수업이 끝나면 자동으로 해제됩니다.
- 교사 콘솔의 `수업 신호 센터`에서 도움 요청, 활동 확인, 연결 상태를 우선순위로 모아 봅니다.
- 온라인 학생 신호에서는 바로 화면 보기, 개인 메시지, 상세 보기를 실행할 수 있습니다.

## 화면 구분성

- 수업 제어는 짙은 라이브 제어 바, 계획은 밝은 수업 흐름 보드, 대응할 일은 짙은 신호 센터로 역할을 분리했습니다.
- 화면 보기·집중·안내 명령은 의도별 묶음으로 다시 배치해, 같은 모양의 버튼이 길게 이어지지 않도록 했습니다.
- 관리자 화면은 학급·명단·권한·보안마다 배경과 색상 체계를 달리해, 같은 카드가 반복되어 보이던 문제를 줄였습니다.
