# Classroom v0.5.29

- 교사 콘솔을 읽기 쉬운 Liquid Glass 작업 공간으로 다듬었습니다. 유리 효과는 탐색과 제어 표면에만 쓰고, 학생 화면과 수업 정보는 높은 대비의 단색 표면으로 유지합니다.
- 수업 제어 막대와 등록·온라인·오프라인·확인 필요 요약 카드의 음수 여백을 제거해 어떤 폭에서도 겹치지 않게 했습니다.
- 상단의 큰 장식 패널을 없애고 인삿말, 날짜, 날씨를 한 흐름으로 정리했습니다. 화면 보기 상세 패널은 이제 전체 콘솔보다 위에 독립적으로 열리며, 실제 학생 화면 비율을 유지합니다.
- 일반 학생 카드와 화면 보기 카드에서 바로 개인 메시지를 보낼 수 있습니다.
- 학생 화면 공유는 최대 720p, 72 KiB 프레임 예산의 자동 화질로 개선되었습니다. 최대 12명 선택 시 약 0.75초, 그보다 많은 전체 학급 화면에서는 안정성을 위해 약 1초 간격으로 갱신합니다.
- `prefers-reduced-motion`, 고대비 환경, 키보드 포커스, 비지원 브라우저의 유리 효과 대체 표면을 함께 보완했습니다.
