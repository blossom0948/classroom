# Classroom v0.5.35

## 학생 화면 연결 및 백그라운드 실행 보완

- 학생 화면 프레임의 서버 수신 한도를 데스크톱 앱·프로토콜과 같은 최대 1280×720 / 72KB로 맞춰, 정상 전송된 화면이 서버에서 버려지던 문제를 수정했습니다.
- 화면 보기용 WebSocket 메시지 한도를 128KB로 정렬해 base64 인코딩된 720p 프레임도 안정적으로 전달합니다.
- 학생 앱 창의 X 버튼은 이제 프로그램을 종료하지 않고 알림 영역으로 숨기며, 화면 공유·상태 연결을 백그라운드에서 계속 유지합니다.
- 실제 종료는 알림 영역의 `프로그램 종료` 또는 앱의 종료 버튼에서 관리자 종료 비밀번호를 검증한 경우에만 진행됩니다.
- 기존 Windows 로그인 자동 시작과 비정상 종료 감시 경로를 유지해, 재부팅 뒤에는 학생 앱이 다시 백그라운드로 연결됩니다.
