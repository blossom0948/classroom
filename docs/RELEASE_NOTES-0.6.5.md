# Classroom v0.6.5

## 예약 시점 선택 확장

- 명령 예약 선택지를 1분부터 7일까지 확장했습니다.
- `직접 설정`에서 원하는 분 수를 입력하거나 정확한 날짜·시각을 지정할 수 있습니다.
- 지난 시각, 7일을 넘는 시각, 두 입력을 동시에 넣는 경우에는 실행 전에 안내합니다.
- 서버도 절대 실행 시각을 검증해 브라우저 시계가 잘못되어도 잘못된 예약이 등록되지 않도록 했습니다.

## 확인 항목

- 웹 품질·Pages 프록시·Worker 다운로드 검사
