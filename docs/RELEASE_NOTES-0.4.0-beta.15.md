# 0.4.0-beta.15

beta.14의 모든 자동 연결·재실 자동화·테마·플로팅 하단바·위젯 기능을 포함한 배포판입니다.

## 주요 기능

- Tailscale 최초 로그인·VPN 승인 뒤 LAN·원격 주소를 자동으로 갱신하고 재연결합니다.
- Windows 11 24H2 이상 지원 PC에서는 내장 재실 센서로 사람이 없어진 뒤 자동 잠금합니다.
- 자동 잠금 해제 신호는 PC 트레이와 휴대폰에 알려 주고, 휴대폰 생체인증 원격 해제 결과는 앱 화면에서 확인합니다.
- Android와 Windows에 시스템·밝게·어둡게 테마를 제공하며 Android는 플로팅 하단바와 빠른 확인 팝업, 위젯 테마·투명도를 제공합니다.
