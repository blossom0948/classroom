# 0.4.0-beta.4

## 이번 버전

- Windows 설정 앱에서 여러 휴대폰을 확인하고 로그인에 사용할 선호 휴대폰을 선택할 수 있습니다.
- Android 앱에서 여러 PC를 등록하고 현재 로그인 대상을 선택할 수 있습니다.
- Windows 설정 앱에 성공·실패·의심스러운 요청의 감사 기록과 원격 IP가 표시됩니다.
- Windows와 Android에 연결·알림·배터리·인증 진단 기능을 추가했습니다.
- 선택한 휴대폰의 인증된 연결이 끊긴 뒤 설정한 유예 시간이 지나면 PC를 잠그는 선택형 보호 기능을 추가했습니다.
- Android에서 강한 생체인증만 허용하거나, Android 시스템의 PIN/패턴/비밀번호를 함께 허용하도록 선택할 수 있습니다.
- 인증 방식 변경 시 키 혼용을 막기 위해 PC별 재페어링을 요구합니다.

## 안전 관련 안내

휴대폰이 가까이 있다는 사실만으로 Windows를 자동 해제하는 기능은 넣지 않았습니다. 근접성은 자동 잠금 보조 신호로만 사용하고, 잠금 해제에는 휴대폰의 생체인증 또는 PIN 인증이 필요합니다. Android가 `BIOMETRIC_WEAK`으로 분류한 얼굴인식은 서명 키 보호에 사용할 수 없습니다.
