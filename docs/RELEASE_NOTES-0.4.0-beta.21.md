# 0.4.0-beta.21

## 사용성

- PC 설정 앱의 시작 충돌을 수정했습니다. WPF 테마 브러시를 안전하게 교체해 설정창이 바로 닫히지 않습니다.
- Windows 설정을 개요·기기·로그인·자동화·원격 제어·네트워크·보안·활동 기록·진단·업데이트로 나눴습니다.
- Android 화면에 PC 전원/잠금 상태 모니터, 상태별 화면, 다크/라이트 테마, 새 플로팅 하단 바를 추가했습니다.
- Android 승인 요청에 실제 남은 시간을 표시하고 만료 시 자동으로 거절합니다. 알림에서도 즉시 거절할 수 있습니다.

## 인증 및 기록

- Windows 로그인 성공 기록의 원인을 휴대폰 생체인식, 인증된 휴대폰 근접 감지, 재실 센서로 구분합니다.
- 로그인 요청은 PC·Windows 계정·휴대폰 단위로 60초에 3회까지 허용하고 초과 시 쿨다운합니다.
- Windows 로그인 화면 문구를 생체인식 승인 흐름에 맞게 정리했습니다.

## 원격 제어

- PC 상태를 Android에 전달해 온라인·잠김·잠금 해제·오프라인을 구분합니다.
- 휴대폰에 12개 버튼의 가로형 Deck 화면을 추가했습니다. 길게 눌러 미디어, 볼륨, 캡처, 앱 실행 등의 허용된 동작을 바꿀 수 있습니다.
- WOL 전송 후 PC가 온라인이 될 때까지 확인하고, 실패 시 외부 LAN 중계기가 필요하다는 상태를 표시합니다.
- Tailscale을 끄지 않고 Samsung Wallet을 앱 기반 분할 터널링에서 제외하도록 설정 안내를 제공합니다.

## Google 로그인

- Firebase 설정 파일이 포함된 빌드에서 Credential Manager 기반 Google 로그인을 사용할 수 있습니다.
- 저장소에는 Google 서비스 설정을 포함하지 않았습니다. Firebase 프로젝트, Android SHA-1, Google provider, `google-services.json`은 배포 환경별로 설정해야 합니다.

## 알려진 제한

- 꺼진 PC는 자체 Tailscale 프로세스가 패킷을 받을 수 없으므로 외부 WOL에는 라우터/NAS/Raspberry Pi 같은 상시 전원 LAN 릴레이가 필요합니다.
- Android에서 지문과 얼굴을 생체인증 결과만으로 항상 구분하는 것은 플랫폼 API 제한으로 지원하지 않습니다. 앱은 정확한 상위 원인인 휴대폰 생체인식으로 표시합니다.
- 실제 Android APK와 Windows 설치본은 GitHub Actions 빌드가 완료된 뒤 릴리스 자산으로 배포됩니다.
