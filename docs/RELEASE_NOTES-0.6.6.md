# Classroom v0.6.6

## 학생 연결 유지 강화

- 학생 화면과 Windows 학생 서비스의 IPC·WebSocket 재연결 루프가 예상하지 못한 예외도 놓치지 않고 계속 재시도합니다.
- 학생 화면 워치독은 설정 로딩, 프로세스 시작, 상태 수집 오류가 발생해도 백그라운드에서 계속 살아서 학생 화면을 다시 실행합니다.
- heartbeat와 화면 상태 루프를 서로 감시해 한쪽이 멈추면 연결 전체를 재생성합니다.
- Windows 서비스가 비정상 종료되는 경우에도 서비스 자체 루프와 Windows 서비스 복구 동작이 다시 연결을 시작합니다.
- 학생 화면이 백그라운드에서 재시작된 원인을 확인할 수 있도록 로컬 진단 로그를 추가했습니다.

- 웹 품질·Pages 프록시·Worker 다운로드 검사
