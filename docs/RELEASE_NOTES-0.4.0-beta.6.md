# 0.4.0-beta.6

## 이번 버전

- 근접 자동 잠금 해제를 실제 무인 동작으로 확장했습니다. 사용자가 Windows 설정에서 **휴대폰이 가까워지면 PC 자동 잠금 해제 (보안 낮음)**을 켠 경우, 인증된 휴대폰 heartbeat가 돌아오면 휴대폰 생체/PIN 확인 없이 Windows Credential Provider가 저장된 자격 증명으로 로그인합니다.
- 이 기능은 명시적 opt-in이고 기본값은 꺼져 있습니다. 집에서만 사용하고, 외부 이동용 PC에서는 켜지 마세요.
- 근접 자동 로그인 요청은 서비스가 연결된 휴대폰의 최신 heartbeat, 선택된 휴대폰, Windows 사용자 SID를 다시 확인한 뒤에만 허용합니다.

## 업데이트 후

1. Windows에서 `PhoneUnlock-Setup.exe`를 설치하고 UAC에서 **예**를 누릅니다.
2. 설정 앱에서 **휴대폰 연결이 끊기면 PC 자동 잠금**을 켜고 **자동잠금 감시 시작**을 누릅니다.
3. 집에서만 사용할 경우 **휴대폰이 가까워지면 PC 자동 잠금 해제 (보안 낮음)**을 별도로 켭니다.
4. Android 얼굴인식이 약한 얼굴인식으로만 제공되면 앱의 호환 모드를 켜고 해당 PC를 다시 연결합니다.
